   Final manuscript outcome remains pending. Inspect the rejected structured

3. **P1, open: the configured daily spending cap is not enforced in application code.**

   Settings definition/loading. `CostLedger.total_usd()` is used for reporting,
   not admission control. The live service loads $10/day; authenticated OpenRouter
   `/api/v1/key` returned HTTP 200 with `limit`, `limit_remaining` and `limit_reset`
   all null. Neither the application nor this key supplies the expected cap.
   Do not confuse bounded retries/output tokens with a daily dollar limit.
4. **Remaining manuscript/source failures are genuine, not fixed by model access.**
   The old HPV manuscript still fails unsupported `author-verified` prose and
   Cross-Domain length 592/850. The old plasma-exchange source check reports
   `STRICT_RETRACTION_BLOCKER` for unverified DOI `10.16016/j.2097-0927.202504031`.
   That is not evidence the source is retracted; it is insufficient verification.
   Other recorded revisions include `revision_repair_incomplete` and a 40-pass
