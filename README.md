# Research Agent

Use the hosted page:

- [research-agent.domlynch.com](https://research-agent.domlynch.com)

Enter:

- Topic
- Domain
- Criteria

Then click `Run`.

The page runs a lean V0 flow:

- one scoped search pass
- one MiMo V2.5 Pro draft pass
- draft rendered below the form
- markdown download saved in `runs/`
